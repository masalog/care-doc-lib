# CareDocLib 画面設計書

| 項目 | 内容 |
|---|---|
| 状態 | 初版・要確認 |
| 対象 | Windows Tauri デスクトップアプリ |

本書は画面構成、主要操作、画面遷移、利用者への通知方針を定める。項目ごとの詳細な配置・寸法は実装時に確認する。

## 1. 画面一覧

| ID | 画面 | 主な利用者 | 状態 |
|---|---|---|---|
| S-01 | ログイン | 担当者、管理者、監査担当者 | 追加 |
| S-02 | 申請書作成 | 担当者、管理者 | 現行画面を拡張 |
| S-03 | 利用者管理 | 担当者、管理者 | 現行画面を拡張 |
| S-04 | 共通設定 | 担当者、管理者 | 現行画面を利用 |
| S-05 | アカウント管理 | 管理者 | 追加 |
| S-06 | バックアップ・復元 | 管理者 | 追加 |
| S-07 | 操作記録 | 監査担当者 | 追加 |

## 2. 画面遷移

```text
アプリ起動
    ↓
S-01 ログイン
    ├─ 担当者・管理者 → S-02 申請書作成
    │                       ├─ S-03 利用者管理
    │                       ├─ S-04 共通設定
    │                       ├─ 管理者のみ：S-05 アカウント管理
    │                       └─ 管理者のみ：S-06 バックアップ・復元
    └─ 監査担当者 → S-07 操作記録
```

- ログアウト後はS-01に戻る。
- 30分間操作がなければ画面をロックし、再認証を求める。
- アプリ起動後は必ずログインを求める。

## 3. 共通画面仕様

- 日本語で表示し、画面名・見出し・項目ラベルを明示する。
- 入力エラーは該当項目の近くに表示し、保存・生成などの処理結果は画面内の通知領域にも表示する。
- 処理中、完了、失敗を区別する。失敗時は成功したように表示せず、可能な次の操作を案内する。
- 役割に許可されていない画面・操作は表示または実行できないようにする。画面上の非表示だけに頼らず、データ操作時にも権限を確認する。
- 個人情報を含む一覧・確認画面は必要な情報に絞り、監査記録には個人情報の値を表示しない。

## 4. 画面仕様

### S-01 ログイン

- **表示項目**：アカウント識別子、パスワード、ログインボタン、エラー表示。
- **操作**：ログイン、終了。
- **結果**：認証成功後、役割に対応した画面へ遷移する。失敗時は理由を過度に開示せず、再入力を促す。
- **未決**：アカウント識別子の形式、パスワード表示切替、失敗回数制限、管理者・監査担当者の初期登録方法。

### S-02 申請書作成

- **表示・入力**：利用者選択、申請年月日、区分変更理由、PDF生成・プレビュー・保存・印刷操作。
- **操作**：利用者を選択し、申請情報を入力してPDFを生成する。区分変更の場合のみ理由を入力する。
- **結果**：PDFを画面内でプレビューする。誤りがあれば利用者情報等を修正して再生成し、確認後に保存・印刷する。
- **表示状態**：アセット読込、準備完了、生成中、生成成功、生成失敗を示す。PDFが表示できない場合は別タブで開く操作を提示する。
- **範囲**：役所への提出はアプリ外。

### S-03 利用者管理

- **一覧**：登録済み利用者を表示し、新規登録、選択、編集、削除を行う。
- **入力項目**：被保険者番号、氏名、フリガナ、生年月日、性別、介護度、住所、電話番号、認定期間、施設入所日。
- **操作**：入力内容を確認して保存する。削除時の確認方法と誤削除時の復旧方法は未決。
- **結果**：保存した情報を全担当者・管理者で共有する。

### S-04 共通設定

- **入力項目**：調査連絡先、入所施設、医療機関、代理人、主治医・クリニックの情報。
- **操作**：設定を表示・編集し、保存する。
- **結果**：保存した共通設定を申請書PDF作成に適用する。担当者・管理者が編集できる。

### S-05 アカウント管理

- **表示項目**：担当者アカウント一覧、アカウント状態。
- **操作**：担当者アカウントの作成・停止、パスワード再設定。
- **権限**：管理者のみ。管理者は監査記録を閲覧できない。
- **未決**：作成・再設定時の確認画面と本人確認方法、操作後の通知内容。

### S-06 バックアップ・復元

- **表示項目**：バックアップ操作、USB上のバックアップ一覧、作成日時、検証結果、処理結果。
- **操作**：管理者が暗号化バックアップをUSBへ手動作成する。復元時はバックアップを選択し、完全性検証と対象確認の後に確定する。
- **結果**：復旧キーはUSB媒体とは別に管理する。検証失敗時は復元せず、エラーを表示する。
- **未決**：USB選択方法、上書き防止、保持期限を超えたバックアップの削除確認。

### S-07 操作記録

- **表示項目**：担当者、日時、対象、操作、結果、変更項目名。
- **操作**：監査担当者が記録を検索・閲覧する。
- **制約**：監査担当者専用アカウントで利用する。管理者と別の人・アカウントとし、記録の変更・削除はできない。個人情報の値は表示しない。
- **記録対象**：担当者の操作に加え、アカウント管理、バックアップ、復元などの管理者操作を含む。
- **未決**：検索条件、並び順、出力機能、5年間の保持期間を過ぎた記録の扱い。

## 5. エラー・確認表示

| 場面 | 表示・動作 |
|---|---|
| 認証失敗 | エラーを表示し、再入力を可能にする。 |
| 入力不備 | 該当項目を示し、修正を促す。 |
| 保存・PDF生成失敗 | 失敗を明示し、入力内容を可能な範囲で保持する。 |
| バックアップ失敗 | 保存先・媒体の状態を確認するよう案内し、成功扱いにしない。 |
| 復元前 | 選択したバックアップと復元対象を確認させ、管理者の確定操作を求める。 |
| 完全性検証失敗 | 復元を中止し、対象バックアップが利用できないことを表示する。 |
| 自動ロック | ロック状態を示し、再認証画面へ遷移する。 |

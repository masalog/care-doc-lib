# CareDocLib 画面設計書

| 項目 | 内容 |
|---|---|
| 状態 | 改訂版（ADR-002 / ADR-003 / ADR-004 反映） |
| 対象 | Windows Tauri デスクトップアプリ |

本書は画面構成、主要操作、画面遷移、利用者への通知方針を定める。認証関連の詳細仕様は [09-auth.md](impl/09-auth.md) を参照。

|---|---|---|---|
| S-01 | 認証（初回セットアップ / ログイン / 15分ロック） | 担当者（1ロール） | 実装済（[09-auth.md](impl/09-auth.md)） |

## 2. 画面遷移

```text
アプリ起動（index.html / admin.html）
    ↓
S-01 認証ガード
    ├─ アカウント0件 → 初回アカウント登録 → ログイン済状態へ
    ├─ 未認証 → ログイン画面
    └─ ロック中 / 15分無操作 → ロック画面オーバーレイ
            ↓（認証・解除成功）
S-02 申請書作成（index.html） ⇄ admin.html
                                  ├─ S-03 利用者管理
                                  ├─ S-04 共通設定
                                  ├─ S-05 バックアップ・復元
                                  └─ S-06 アカウント管理
```

- ログアウト後はログイン画面に戻る（`sessionStorage` を破棄し画面状態を初期化する）。
- 15 分間操作がなければロック画面オーバーレイを表示し、現在のログインユーザーの 4 桁 PIN 再入力で解除する。別ユーザーへ切り替える場合はログアウトする。
- アプリ起動後は毎回ログインを求める（ウィンドウ終了でセッションは破棄される）。

## 3. 共通画面仕様

- 日本語で表示し、画面名・見出し・項目ラベルを明示する。
- 業務画面のヘッダーに「ログイン中の担当者名」「画面ロック」「ログアウト」を表示する。
- 入力エラーは該当項目の近くまたはメッセージ領域に表示し、保存・生成などの処理結果も通知領域に表示する。
- 処理中、完了、失敗を区別する。失敗時は成功したように表示せず、可能な次の操作を案内する。
- 未認証・ロック状態で業務画面内容が画面上にチラつかないよう、認証完了まで業務領域を非表示にし、データ操作の入口でもセッションを確認する。

## 4. 画面仕様

### S-01 認証（初回セットアップ / ログイン / ロック）

- **初回セットアップ（アカウント 0 件時）**：アカウントID、表示名、PIN（4桁数字・確認入力含む）、登録ボタン。
- **ログイン**：アカウントID、PIN（4桁数字）、ログインボタン、エラー表示。
- **15分ロック（オーバーレイ）**：ロック中メッセージ、現在のアカウント名、PIN 再入力欄、解除ボタン、別ユーザー用にログアウトボタン。
- **結果**：認証成功後、業務画面を表示（ロック解除時は入力中フォームを維持してオーバーレイを閉じる）。失敗時は理由を過度に開示せず、再入力を促す。

### S-02 申請書作成（`index.html`）

- **表示・入力**：利用者選択、申請年月日、変更更新理由、PDF 生成・プレビュー・ダウンロード・別タブ表示操作。
- **操作**：利用者を選択（または新規入力・保存）して PDF を生成する。変更更新の場合のみ理由を入力する。
- **結果**：PDF を画面内でプレビューする。誤りがあれば修正して再生成し、確認後にダウンロード・印刷する。
- **表示状態**：アセット読込、準備完了、生成中、生成成功、生成失敗を示す。
- **範囲**：役所への提出はアプリ外。

### S-03 利用者管理（`admin.html`）

- **一覧**：登録済み利用者を表示し、新規登録、編集、削除、および最終更新者・更新日時の確認を行う。
- **入力項目**：被保険者番号、氏名、フリガナ、生年月日、性別、介護度、住所、電話番号、認定期間、施設入所日。
- **操作**：入力内容を確認して保存する。削除時は確認ダイアログを表示する。
- **結果**：保存した情報を端末内の全担当者で共有し、作成者・更新者を記録する。

### S-04 共通設定（`admin.html`）

- **入力項目**：調査連絡先、入所施設、医療機関、代理人、主治医・クリニックの情報。
- **操作**：設定を表示・編集し、保存する。
- **結果**：保存した共通設定を申請書 PDF 作成に適用し、作成者・更新者を記録する。

### S-05 バックアップ・復元（`admin.html`）

- **表示項目**：書き出しボタン、復元用ファイル選択、個人情報取り扱いに関する注意文、処理結果メッセージ。
- **操作**：担当者が JSON ファイル（`caredoc-backup` v1）を手動書き出しする。復元時はファイル選択後に形式検証・確認ダイアログ・復元前自動バックアップを経て全件置き換えする。
- **結果**：検証失敗時は復元せず、エラーを表示する。アカウント情報や更新者メタデータは書き出しに含めない。

### S-06 アカウント管理（`admin.html`）

- **表示項目**：アカウント一覧（アカウントID、表示名、更新日時）、作成・編集・最後1件削除用PIN確認フォーム、処理結果メッセージ。
- **操作**：新規アカウント作成、表示名変更、PIN 変更・再設定、削除（最後の 1 件削除時は現在の PIN 再入力を必須とする）。
- **権限**：ログイン済み担当者（1ロール共通）。PIN 平文は表示しない。

## 5. エラー・確認表示

| 場面 | 表示・動作 |
|---|---|
| 認証失敗 | 「アカウントIDまたはPINが正しくありません」等のエラーを表示し、再入力を可能にする。連続 5 回失敗時は 1 時間の一時ロック時間を案内する。 |
| 入力不備 | 該当項目またはメッセージ欄を示し、修正を促す。 |
| 保存・PDF生成失敗 | 失敗を明示し、入力内容を可能な範囲で保持する。 |
| バックアップ検証失敗 | 復元を中止し、エラー理由を表示する。既存データは変更しない。 |
| 復元前 | 現在の件数・バックアップ件数・保存日時を示し、確認ダイアログで確定を求める。 |
| 15分自動ロック | ロック画面オーバーレイを表示し、PIN 再入力またはログアウトを促す。 |
